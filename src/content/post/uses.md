This is a small, evolving list of the tools and workflows I use day to day. It is not a full inventory; detailed machine setup and bootstrap notes live in my dotfiles.

## Development

- [cmux](https://cmux.com/) as my main terminal/workspace environment, based on `Ghostty`. I use it for terminal sessions, split panes, and agent-oriented development workflows.
- Shell and machine setup managed in my [dotfiles](/projects/dotfiles/), mostly around `zsh`/`ash`-style workflows. The detailed bootstrap package list lives in the [dotfiles repo](https://github.com/shdennlin/dotfiles) instead of on this page.
- [Neovim](https://neovim.io/)
- [Svelte](https://svelte.dev/) for interactive web UI work
- [Astro](https://astro.build/) for this site
- `TypeScript` for most web-facing work
- `Go` and `Python` for backend services, scripting, and automation
- [Bun](https://bun.sh/) for JavaScript/TypeScript package management, local development, and builds
- [asdf](https://asdf-vm.com/) for runtime version management
- [GitHub](https://github.com/) for source control and public project notes
- [Cloudflare Pages](https://pages.cloudflare.com/) for hosting this blog
- [CyberChef](https://gchq.github.io/CyberChef/) for quick encoding, decoding, and ad-hoc data transforms
- [croc](https://github.com/schollz/croc) for secure peer-to-peer file transfer between machines

## Lab and infrastructure

- [Proxmox VE](https://www.proxmox.com/en/proxmox-virtual-environment/overview) for local virtualization and lab environments
- [Docker](https://www.docker.com/) and [Docker Compose](https://docs.docker.com/compose/) for local services
- [Kubernetes](https://kubernetes.io/) for container orchestration and deployment experiments
- [Kali Linux](https://www.kali.org/) for security testing workflows
- [Immich](https://immich.app/) for self-hosted photo management

## AI-assisted workflow

- [ChatGPT](https://chatgpt.com/), [Claude Code](https://www.anthropic.com/claude-code), and [Codex](https://github.com/openai/codex) for implementation, review, and debugging loops
- AI tools for breaking down requirements, exploring approaches, writing drafts, and checking edge cases
- [Spectra](https://spectra.5xcamp.us/) for spec-driven development workflows: turning vague ideas into structured proposals, tasks, and implementation plans before coding
- [rtk](https://github.com/rtk-ai/rtk/tree/develop) as a CLI proxy that trims LLM token usage on common dev commands
- Small scripts and utilities when a repeated workflow starts to get annoying

## Planning

- [Linear](https://linear.app/) as a personal project manager
- [issue-graph](https://github.com/shdennlin/issue-graph), my self-hosted issue dependency graph viewer (Linear today, more sources later)
- [Mermaid](https://mermaid.js.org/) for diagrams and technical notes

## Notes and writing

- [Obsidian](https://obsidian.md/) as the private note-taking environment
- [Notion](https://www.notion.com/) for structured notes, planning, and shared documents
- Plain `Markdown` as the long-term content format
- This blog as the public layer for notes that are useful enough to keep outside the vault

## What I care about

I tend to prefer tools that make work easier to reason about: **fast feedback**, **plain files**, **portable data**, and workflows that can survive being moved to a different stack later.

## Everyday tools

- [Arc](https://arc.net/) as my main browser
- [Bitwarden](https://bitwarden.com/) for password management
- [Setapp](https://setapp.com/) for a rotating set of Mac apps without per-app subscriptions
- [Easydict](https://github.com/tisfeng/Easydict) for dictionary lookups and translation on macOS
- [VoiceInk](https://github.com/Beingpax/VoiceInk) for local, no-subscription voice-to-text on macOS
